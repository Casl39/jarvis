# J.A.R.V.I.S.

Голосовой ассистент в стиле Железного человека. «Мозг» — локальный сервер
[OpenCode](https://opencode.ai). На Windows и Arch Linux это **отдельное
настольное приложение** со своим окном (WebView2 / WebKit2GTK), на Android —
устанавливаемое PWA. Голос — нейросетевой Edge TTS («джарвисовский» британский
и русский мужской голос), с резервным голосом браузера.

- **Сервер OpenCode запускается автоматически** вместе с `Jarvis.exe` и
  останавливается вместе с ним. Пароль вводить не нужно.
- Голосовой ввод на русском (Web Speech API).
- Ответы озвучиваются нейроголосом Edge TTS; длинные ответы сокращаются.
- Режим «Джарвис»: ассистент ждёт обращения по имени.
- Понимает локальные команды: «стоп», «новый диалог», «настройки», «история»,
  «тише», «громче».
- Видит файлы и терминал в выбранной рабочей папке — через OpenCode.
- Никаких ключей API в браузере: всё общение идёт через локальный сервер
  OpenCode.

```
Настольное окно (WebView2 / WebKit2GTK)
   UI, голос  ──HTTP──▶  встроенный сервер  ──HTTP+Basic──▶  opencode serve
                          статика + /oc + /tts              модели, инструменты
```

## Что нужно

1. **OpenCode**. На Windows приложение `Jarvis.exe` запускает сервер
   автоматически — отдельно ничего запускать не нужно. Вручную:

   ```bash
   # Arch Linux / macOS
   opencode serve --port 4096

   # Windows (PowerShell)
   opencode serve --port 4096
   ```

   Сервер слушает только `127.0.0.1`. Пароль не нужен: приложение само
   управляет доступом к запущенному им серверу.

2. **Windows 10/11** — компонент «Microsoft Edge WebView2 Runtime» (обычно уже
   установлен вместе с Edge). Для сборки приложения — .NET Framework 4.x.

3. **Arch Linux** — Python 3.8+, `python-gobject` и `webkit2gtk-4.1` для
   отдельного окна. `edge-tts` ставится скриптом установки.

## Быстрый старт

### Windows — готовое приложение

Готовая сборка лежит в `desktop\dist\`:

```cmd
desktop\dist\Jarvis.exe
```

Приложение поднимает свой сервер интерфейса на порту 8737 (или следующем
свободном), открывает окно и работает без браузера. Сервер OpenCode
запускается **автоматически** и останавливается вместе с приложением. Если
OpenCode уже запущен и доступен без пароля, приложение подключится к нему.
Если порт занят чужим сервером с паролем — поднимет свой на свободном порту.

Настройки можно задать в `desktop\dist\jarvis.config.json` рядом с `Jarvis.exe`:

```json
{
  "opencodeUrl": "http://127.0.0.1:4096",
  "autoStartServer": true,
  "opencodeBin": "",
  "port": 8737,
  "devTools": false
}
```

`opencodeBin` — путь к `opencode.exe` / `opencode-cli.exe`, если он не найден
автоматически (PATH, OpenCode Desktop, npm). `port` — порт окна приложения;
фиксированный порт нужен, чтобы настройки и история сохранялись между
запусками (`localStorage` привязан к адресу).

Пересобрать приложение из исходников:

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build-windows.ps1
```

Скрипт компилирует `desktop\Jarvis.cs`, копирует интерфейс, WebView2 и
переносимый Python с `edge-tts` в `desktop\dist\`.

Резервный браузерный режим на Windows (без WebView2):

```cmd
start-windows.cmd
```

### Arch Linux — отдельное окно

```bash
cd desktop
./install-arch.sh
jarvis-app
```

`install-arch.sh` проверит зависимости, установит `edge-tts`, создаст ярлык в
меню приложений и команду `jarvis-app`. Либо из корня проекта:

```bash
./start-arch.sh
```

Скрипт откроет окно WebKit2GTK, а если библиотек нет — резервный браузер.

Вручную (сервер OpenCode запустите заранее командой
`opencode serve --port 4096`):

```bash
python3 desktop/jarvis-app.py
# или браузерный режим:
python3 serve.py --open
```

Порт по умолчанию — 8000. Если он занят, сервер возьмёт следующий свободный
(8001, 8002, …) и напишет адрес в консоли.

### Android

1. Запустите сервер с доступом из локальной сети:

   ```bash
   # Arch
   python3 serve.py --lan

   # Windows
   powershell -ExecutionPolicy Bypass -File serve.ps1 -Lan
   ```

2. Телефон и компьютер должны быть в одной Wi-Fi сети. Откройте на телефоне
   адрес, который напечатает сервер, например `http://192.168.1.20:8000`.

3. В Chrome откройте меню → **Добавить на главный экран** / **Установить
   приложение**. Появится иконка J.A.R.V.I.S. Нейроголос при этом синтезируется
   на компьютере (если там установлен `edge-tts`).

**Важно про микрофон на Android.** Chrome разрешает микрофон только на
`https://` или `localhost`. Для доступа по IP включите флаг:

1. Откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
2. Добавьте `http://192.168.1.20:8000` (свой адрес) в список.
3. Перезапустите Chrome.

Альтернатива — завернуть сервер в HTTPS-прокси (Caddy, nginx). Текстовый ввод
работает и без этого.

**Важно про голосовой ввод на Arch.** WebKit2GTK не реализует
`webkitSpeechRecognition`, поэтому в отдельном окне Arch доступен текст и
нейроозвучка, а микрофон — в браузерном режиме Chrome/Chromium. На Windows
WebView2 поддерживает и распознавание, и синтез: голосовой ввод работает в
самом приложении.

## Настройки приложения

Шестерёнка в правом верхнем углу:

| Поле | Что значит |
| --- | --- |
| Адрес OpenCode | `/oc` — встроенный прокси. Можно указать `http://127.0.0.1:4096` напрямую, но тогда нужен CORS в OpenCode. |
| Рабочая папка | Папка, в которой Джарвис читает и меняет файлы. Пусто — папка, из которой запущен OpenCode. |
| Модель | Модель OpenCode. «По умолчанию» — как в настройках OpenCode. |
| Агент | `jarvis` — краткие ответы «вслух». Ставится автоматически при первом запуске сервера. |
| Голос | Язык распознавания, движок озвучки (нейроголос / браузер), нейроголос, резервный голос браузера, скорость, режим «Джарвис», звуковые сигналы. |

Модель и агент применяются к **новому** диалогу. Рабочая папка тоже
фиксируется при создании сеанса — после смены папки начните новый диалог.

## Агент `jarvis`

При первом запуске `serve.py` / `serve.ps1` / настольного приложения
`agents/jarvis.md` копируется в
`~/.config/opencode/agents/jarvis.md` (на Windows — `C:\Users\<вы>\.config\opencode\agents\jarvis.md`).
Агент просит модель отвечать по-русски, коротко и без разметки — так ответы
приятнее слушать. OpenCode подхватывает файл без перезапуска.

Обновить агента вручную:

```bash
python3 serve.py --install-agent                                      # Arch
powershell -ExecutionPolicy Bypass -File serve.ps1 -InstallAgent      # Windows
```

Если агент не установлен, приложение работает с агентом OpenCode по умолчанию.

## Голос

- Кнопка микрофона или **Ctrl+Space** — начать/остановить прослушивание.
- Режим «Джарвис»: скажите «Джарвис, …» — фраза после имени уйдёт в OpenCode.
  Без имени ассистент игнорирует речь.
- «Стоп» / «Замолчи» — прервать ответ и озвучку.
- «Новый диалог» — новый сеанс.
- «Настройки», «История», «Очисти экран» — панели.
- «Тише» / «Громче» — скорость речи.

### Нейроголос Джарвиса

Озвучка по умолчанию идёт через **Edge Neural TTS**:

| Голос | Когда используется |
| --- | --- |
| `ru-RU-DmitryNeural` | русский текст (мужской, спокойный) |
| `en-GB-RyanNeural` | английский текст (британский мужской, «джарвисовский») |
| `ru-RU-SvetlanaNeural` | русский женский, если выбрать вручную |

В настройках:

- **Движок озвучки** — «Авто» (нейроголос, если доступен), «Нейроголос (Edge)»,
  «Голос браузера».
- **Нейроголос** — конкретный голос или «Авто (по языку)».
- **Голос браузера (резерв)** — используется, если нейроголос недоступен.

На Windows нейроголос встроен в приложение: переносимый Python и `edge-tts`
лежат в `desktop\tts\`, интернет нужен только для самого синтеза. На Arch
установите пакет:

```bash
python3 -m pip install --user edge-tts
```

Синтез кэшируется, поэтому повторные фразы звучат мгновенно. Если сеть или
сервис недоступны, приложение автоматически переходит на голос браузера.

Длинные ответы озвучиваются частично: примерно 400 символов и фраза
«Подробности на экране, сэр». Полный текст всегда остаётся в чате.

## Безопасность

- `serve.py` / `serve.ps1` по умолчанию слушают только `127.0.0.1`.
- `--lan` открывает интерфейс всей локальной сети и даёт доступ к вашему
  OpenCode. Используйте только в доверенной сети.
- `Jarvis.exe` сам управляет паролем запущенного им сервера OpenCode: пароль
  генерируется случайно, хранится только в памяти и не показывается в
  интерфейсе.
- Приложение не отправляет данные никуда, кроме вашего OpenCode.

## Частые проблемы

**401 / «нет связи».** `Jarvis.exe` поднимает сервер сам. Если порт 4096 занят
чужим сервером с паролем, приложение автоматически выберет свободный порт —
просто подождите несколько секунд. Если сервер не найден, укажите путь к
`opencode.exe` в `opencodeBin` (или переменной `OPENCODE_BIN`).

**«Нет связи» в браузерном режиме.** Запустите `opencode serve --port 4096` и
проверьте адрес в настройках — `/oc` (прокси) или `http://127.0.0.1:4096`.

**Микрофон не работает.** В приложении Windows микрофон разрешается
автоматически. В браузере нужен Chrome/Edge и `https://` или `localhost`.
Для IP-адреса — флаг из раздела про Android. Проверьте, что сайту разрешён
доступ к микрофону (иконка в адресной строке).

**Нейроголос молчит.** Проверьте интернет и наличие `edge-tts` (`pip show
edge-tts`). В настройках включите «Движок озвучки → Авто». Если сервис
недоступен, приложение само переключится на голос браузера.

**Порт занят.** Сервер сам попробует следующие 12 портов и напечатает
фактический адрес.

**На телефоне старый интерфейс.** Service worker обновляется в фоне: закройте
и откройте приложение ещё раз. Жёсткое обновление — потяните страницу вниз.

**Долгие ответы обрываются.** Так работает озвучка: вслух читается начало,
полный текст остаётся на экране. Увеличить лимит можно в `shortenForSpeech`
в `js/app.js`.
